## Resumen

La Situación 1 deja listo el panel longitudinal 2021-2025 con fuentes satelitales, meteorología y verdad observada DAGMA/CVC. El panel se publica en GCS, Hugging Face y Kaggle para ser consumido por las situaciones 2 y 3.
